# Ahmed Abdihakim — Frontend Portfolio

A high-performance, editorial frontend portfolio crafted with React 19, TypeScript, Vite, Tailwind CSS, and Framer Motion. Featuring an Obsidian, Ivory, and Electric Lime design aesthetic inspired by Linear and Vercel.

## 🚀 Live Projects

- **DevGear**: [https://devgear.byahmed.dev](https://devgear.byahmed.dev) · [GitHub](https://github.com/Jamalabdirahiim/DevGear)
- **SOON**: [https://soon.byahmed.dev](https://soon.byahmed.dev) · [GitHub](https://github.com/Jamalabdirahiim/soon-final)

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design Tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router v7

---

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Jamalabdirahiim/MyPortflio.git
   cd MyPortflio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
